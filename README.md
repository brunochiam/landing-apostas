# Aposta contra você: página educativa

Landing page educativa da campanha de conscientização sobre apostas online.
Projeto acadêmico do TCC II de Publicidade ("Ética Publicitária no Ambiente Digital").

**Simulação acadêmica:** sem vínculo oficial com a Prefeitura de Curitiba, que é cliente fictício deste projeto.

Equipe: Bruno, André Medeiros e Miguel Atanazio.

## Estrutura
- `index.html`: página
- `css/styles.css`: estilos (paleta e tipografia do Sistema Visual V2)
- `img/`: KVs aprovados e fotos

Página estática, sem dependências além da fonte Inter (Google Fonts). Textos marcados como `[COPY PENDENTE]` ainda serão definidos.
